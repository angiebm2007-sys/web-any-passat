# Web del curs anterior

## Descripció
Aquest projecte recupera la pàgina web desenvolupada anteriorment durant el curs. Inclou HTML, CSS, JavaScript i els recursos necessaris pel seu funcionament. És una web sobre un festival de música a la ciutat de Lleida, on es poden veure els horaris d'esdeveniments, preguntes freqüents, subscriure't, etc... 

## Tecnologies utilitzades
- HTML
- CSS
- JavaScript
- Firebase Hosting

## Ejecució local
Obre l'arxiu `index.html` a un navegador per visualitzar la pàgina web.

## Publicación
La web està publicada mitjancant Firebase Hosting.

**URL:** (https://web-any-passat.web.app)
